Everything BetterDisplay Pro Has.
100% Free Forever.

Engineered with low-level Apple Silicon I2C DDC/CI, SkyLight private APIs, and cross-platform native drivers.

⚡

Hardware DDC/CI Control

Direct Apple Silicon & Intel hardware communication for brightness, contrast, audio volume, mute, and input switching over HDMI/DisplayPort/USB-C.

📐

Native Resolution & HiDPI

Switch between all available display modes with live refresh rate tracking, Retina pixel doubling, and ultra-wide aspect ratios.

🔌

True Display Power & Sleep

Turn individual screens on/off without affecting other displays. Uses hardware DPMS, SkyLight window server disconnection, and zero-gamma LUT blackout.

📺

Underscan & Overscan Sizing

Compensate for cropped TV/Projector bezels with adjustable 0%–25% underscan framing and hardware VCP geometry scaling.

✨

Smart Panel Intelligence

Automated PPI, diagonal size, aspect ratio, and panel gamut calculation with 1-click optimal color profile & refresh rate calibration.

⌨️

Global Shortcuts & Bezel OSD

Control brightness, volume, power, and presets with customizable keyboard hotkeys and macOS-native translucent on-screen display HUDs.

🎭

Display Presets & Groups

Switch between Day, Night, Gaming, and Focus modes instantly, or synchronize brightness & volume across custom display groups.

🌐

macOS, Linux & Windows

Full cross-platform support with system tray popovers, CLI automation, and native hardware drivers on all 3 major operating systems.

Built for Every Desktop OS

Identical system tray experience and hardware control wherever you work.

macOS Quick Run 
# Build & run directly on macOS (Apple Silicon & Intel)
git clone https://github.com/bhavukar/monik.git
cd monik
./scripts/build_app.sh
open "build/Manage Your Display.app"
Linux System Tray & CLI 
# Install I2C dependencies and run system tray GUI
chmod +x linux/install.sh
./linux/install.sh
python3 linux/manage_your_display_gui.py

# Or use CLI
displaycraft detect
Windows System Tray 
# Run Windows Flutter controller
flutter run -d windows
