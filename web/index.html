CAPABILITIES

Built for power users. Simple for everyone.

Low-level I2C bus control and window-server integration with zero unnecessary bloat.

HARDWARE ENGINE

Native DDC/CI Protocol Communication

Direct I2C hardware bus control for Apple Silicon (M1/M2/M3/M4) and Intel Macs. Adjust hardware brightness, contrast, volume, input sources, and DPMS sleep over HDMI, DisplayPort, and USB-C.

INDEPENDENT POWER

Discrete Screen Power

Toggle any display ON or OFF independently without waking sleeping monitors or scrambling open windows via SkyLight window-server management and zero-gamma LUT blackout.

RESOLUTION & REFRESH

Native Resolution Dropdown

Switch resolutions, HiDPI 2x Retina modes, and high refresh rates (up to 144Hz+) instantly via a clean native dropdown menu instead of clunky sliders.

BEZEL GEOMETRY

Underscan & Overscan Sizing

Compensate for cropped TV or projector bezels with custom 0%–25% hardware letterboxing and VCP geometry scaling.

COLOR & PPI CALIBRATION

Automated Panel Intelligence

Instant mathematical calculation of screen diagonal inches, pixel density (PPI), and aspect ratio with 1-click Display P3 vs sRGB color calibration presets.

OPEN SOURCE

Cross-platform installation.

Runs natively across macOS, Linux, and Windows.

macOS • Native Swift Release 
git clone https://github.com/bhavukarora/monik.git
cd monik
./scripts/build_app.sh
open "build/Manage Your Display.app"
Linux • PyQt6 & ddcutil 
chmod +x linux/install.sh
./linux/install.sh
python3 linux/manage_your_display_gui.py
Windows • DXVA2 & Flutter 
flutter run -d windows
