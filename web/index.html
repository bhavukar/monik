Essential capabilities. Zero clutter.

Everything you need to orchestrate multi-monitor desks with low-level precision.

01

Hardware DDC/CI Engine

Control external monitor brightness, contrast, volume, input selection, and DPMS sleep over HDMI, DisplayPort, and USB-C.

02

Discrete Screen Power

Toggle any display ON or OFF independently without affecting others via SkyLight window-server and zero-gamma LUT blackout.

03

Native Resolution Dropdown

Instantly switch between native, HiDPI Retina, and high-refresh rates (up to 144Hz+) using a clean, accessible dropdown selector.

04

Underscan & Overscan Sizing

Compensate for cropped TV or projector bezels with adjustable 0%–25% edge padding and hardware VCP geometry scaling.

05

Smart Panel Intelligence

Automated calculation of screen diagonal inches, pixel density (PPI), and aspect ratio with 1-click optimal color profile tuning.

06

Global Hotkeys & Bezel OSD

Adjust brightness and volume or switch presets globally with keyboard shortcuts and translucent macOS bezel HUD feedback.

Cross-platform installation.

Runs natively across macOS, Linux, and Windows.

macOS • Native Swift Release 
# Clone and build native .app bundle
git clone https://github.com/bhavukarora/monik.git
cd monik
./scripts/build_app.sh
open "build/Manage Your Display.app"
Linux • PyQt6 & ddcutil 
# Install I2C modules and run system tray GUI
chmod +x linux/install.sh
./linux/install.sh
python3 linux/manage_your_display_gui.py
Windows • DXVA2 & Flutter 
# Run Windows system tray application
flutter run -d windows
