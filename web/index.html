TOP CAPABILITIES

Essential capabilities. Zero clutter.

Engineered with low-level kernel & DDC/CI precision for complete multi-monitor mastery.

1

Hardware DDC/CI Control

Direct I2C hardware communication on Apple Silicon & Intel. Adjust brightness, contrast, and audio volume over HDMI, DisplayPort, and Type-C.

2

Discrete Screen Power

Turn any display ON or OFF independently without disturbing window arrangements via SkyLight window-server and zero-gamma LUT blackout.

3

Native Resolution Dropdown

Switch resolutions and refresh rates (up to 144Hz+) instantly via a clean native dropdown menu instead of confusing sliders.

4

Underscan & Overscan Sizing

Compensate for cropped TV or monitor bezels with custom 0%–25% hardware letterboxing and VCP geometry scaling.

5

Automated Panel Intelligence

Mathematical calculation of screen diagonal inches, pixel density (PPI), and aspect ratio with 1-click Display P3 / sRGB color calibration.

6

Cross-Platform Open Source

Native Swift release for macOS, PyQt6 & ddcutil for Linux, and DXVA2 for Windows. 100% free under the MIT License.

Cross-platform installation.

Runs natively across macOS, Linux, and Windows.

macOS • Native Swift Release 
# Clone and build native .app bundle
git clone https://github.com/bhavukarora/monik.git
cd monik
./scripts/build_app.sh
open "build/Manage Your Display.app"
Linux • PyQt6 & ddcutil 
# Install I2C modules and run system tray GUI
chmod +x linux/install.sh
./linux/install.sh
python3 linux/manage_your_display_gui.py
Windows • DXVA2 & Flutter 
# Run Windows system tray application
flutter run -d windows
